# 0921 prototype 작업내역

## 다크 팝업 선택 메뉴

- 정렬 및 상세 폴더 선택의 브라우저 기본 드롭다운을 차콜 팝업으로 교체.
- 둥근 모서리, 블루 선택 배경, 체크 표시로 기존 디자인 체계 유지.
- 바깥 클릭/Esc 닫기, 방향키 선택 이동, 선택 후 포커스 복원 구현.
- 브라우저에서 오래된순 선택 후 카드 순서 변경 확인.

## 2026-09-23 뒤로가기 시간 조정

- 상세 뒤로가기를 400ms로 변경. 진입 500ms 및 양쪽 이동 곡선은 유지.

## 2026-09-23 상세 전환 시간 통일

- 상세 진입과 뒤로가기를 모두 500ms로 통일. 각 이동 곡선과 페이드 없는 슬라이드는 유지.

## 상세 진입 속도 완화

- 진입 시간을 400ms에서 650ms로 늘림.
- cubic-bezier(.32,.05,.2,1)로 초반 급출발을 줄이고 끝에서 천천히 안착하도록 조정.
- 페이드 없는 페이지 이동, 포커스 자동 스크롤 방지 및 뒤로가기 300ms 유지.

## 상세 진입 감속 조정

- 진입 400ms 유지. 끝에서 가속되던 곡선을 cubic-bezier(.25,.1,.25,1)로 변경해 부드럽게 감속하도록 조정.
- 뒤로가기 300ms와 기존 복귀 곡선은 변경하지 않음.

## 상세 진입 시간 조정

- 상세 진입 400ms, 뒤로가기 300ms. 이동 곡선과 페이드 없는 슬라이드 방식 유지.

## 상세 진입 시 상단 튐 방지

- 슬라이드 중 뒤로가기 버튼 포커스가 부모 화면을 자동 스크롤하지 않도록 preventScroll 적용.
- 복귀 포커스에도 동일 적용. 300ms 페이지 슬라이드와 기존 스크롤 위치 유지.

## 상세 진입·복귀 모션 일치

- 상세 진입도 복귀와 동일하게 300ms, cubic-bezier(.4,0,.7,.3) 적용.
- 페이드 없이 전체 너비 슬라이드를 유지하며 진입·복귀 방향만 반대로 구성.

## 페이지 슬라이드 방식으로 통일

- 화면 전환의 투명도 변화 제거. 상세 진입은 전체 너비만큼 우측에서 들어오며 620ms, 복귀는 우측으로 나가며 300ms.
- 탭과 폴더 진입/복귀는 이전 화면과 다음 화면이 함께 좌우로 이동하는 360ms 전환으로 변경.
- 카드·폴더 개별 페이드 등장 제거. 필터·검색 결과는 즉시 갱신.
- 콘텐츠 추가 패널은 아래에서 올라오고 닫을 때 아래로 내려감. 알림도 투명도 변화 없이 이동.
- V1 보존. 동작 줄이기 설정 유지.

## 상세 화면 왕복 모션 조정

- 진입 시간을 340ms에서 620ms로 늘리고 완만한 감속 곡선 적용.
- 뒤로가기와 Escape에 300ms 우측 이동·페이드아웃 적용(요청에 따라 420ms에서 단축). 완료 후 화면 숨김 및 이전 포커스 복원.
- 중복 닫기 방지, 초기화 시 즉시 닫기, 동작 줄이기 설정 지원.

## 애니메이션 추가

- 작업 폴더의 현재 이름인 `prototype V2`에서 작업. V1 변경 없음.
- `motion.css` 추가: 카드·폴더 순차 등장, 상세 화면 슬라이드, 콘텐츠 추가 패널 등장, 토스트 등장, 버튼 누름/호버 반응.
- 탭 이동 방향을 반영한 280ms 전환 추가. 연속 전환 시 이전 모션 취소.
- 원본 검색 진행 중 상태에 은은한 투명도 변화 적용.
- animation-systems 기준으로 transform/opacity 중심 구현, OS 동작 줄이기 설정 지원.
- JavaScript 구문 검사 및 브라우저 폴더/추가 패널의 애니메이션 적용 확인.
- 현재 실행 주소: http://localhost:4173/prototype%20V2/dark-v2.html
