# V3 검증 기록

검증일: 2026-10-04 · 대상: `http://127.0.0.1:4173/prototype%20V3/index.html`

## 실제 브라우저에서 확인

- 1280×720 데스크톱, 390×844 및 320×740 모바일 뷰포트 레이아웃
- 320px에서 문서 가로 넘침 없음. 플랫폼 필터 행은 의도적인 가로 스크롤
- 피드 드래그 → 항목 열기 → 이전 화면 복귀
- 링크 추가 → 폴더·키워드 편집 → 새로고침 후 데이터 유지
- 로컬 JPG 선택 → 저장 → 이미지 상세 및 원본 링크 없음 표시
- 즐겨찾기 선택/해제
- 메모 닫기 시 자동 저장 → 해당 메모 검색 → 메모 삭제 후 결과 0개로 갱신
- 정렬 팝업 방향키/Enter 선택 및 정렬 버튼으로 포커스 복귀
- 추가 화면 링크/이미지 탭 방향키 전환
- 삭제 → 실행 취소 → 항목·폴더·즐겨찾기 복원
- 모바일 도움말·내보내기 접근. JSON 다운로드 파일 파싱 및 테스트 항목 포함 확인
- 격자 피드 상세 수정 전후 내부 스크롤 594px 유지, 원래 항목으로 포커스 복귀
- 빈 폴더에서 필터 초기화가 아닌 첫 항목 추가 동작 제공
- 모바일 상세 뒤로가기 좌표 x=22, y=32, 44×44px로 폴더 뒤로가기와 정렬
- 확인한 브라우저 세션에서 console error/warn 없음

테스트용 링크·이미지 2개는 검증 후 제거했고, 시안에는 샘플 9개를 남겼습니다. 내보내기 테스트 파일은 다운로드 폴더의 `storyge-backup.json`입니다.

## 자동 검사

- `node --check app.js`, `node --check store.js`, `node --check orbit.js` 통과
- `node --test store.test.cjs`: 6개 통과
- 피드 격리 테스트: 0/1/2/9/25/100/1000개 좌표, 드래그·취소, 키보드 탐색, pause/resume/destroy. 이는 실제 기기 FPS 측정이 아닌 합성 DOM 테스트
- AI-slop 스캔 수동 검토: 원형 피드·즐겨찾기의 원형은 의도된 형태. `-webkit-touch-callout`은 오탐. 장식용 그라데이션·반복 캐치프레이즈·임의 SVG 아이콘은 추가하지 않음

## 한계

실제 iPhone/Android 하드웨어, VoiceOver/TalkBack, 브라우저별 OS 키보드 및 파일 선택기, 서비스 규모 성능, 백엔드/AI/인증은 검증하지 않았습니다. 모션 축소는 코드와 피드 격리 테스트에 반영되어 있으나 OS 설정을 변경한 실기기 검증은 별도로 필요합니다. 수천 개 항목의 가상화, 여러 탭 동시 편집 충돌, 계정·동기화·웹 클리퍼 확장은 후속 개발 범위입니다.
